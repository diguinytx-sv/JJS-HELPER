DESCRIÇÃO
---------
Script de interface para o Roblox Skill Builder.
Painel flutuante com guias, checklists e dicas
organizadas por categoria. Funciona no PC e
no celular. Não simula teclas nem injeta inputs.


COMO USAR
---------
1. Execute o script no seu executor.
2. O painel abre automaticamente no centro da tela.
3. Arraste pelo Header (área do logo + nome).
4. Clique em qualquer ferramenta para ver o guia.
5. Use o botão VOLTAR para fechar o guia aberto.
6. Use − para minimizar e X para fechar.
